## IWSM_2027

Notes for workshop at the [International Workshop on Statistical Modelling](https://iwsm2027.com/), Bilbao 2027

## Topics

Defining, setting up, fitting, diagnosing, and interpreting [mixed models](https://en.wikipedia.org/wiki/Mixed_model). The workshop will be focused on the R ecosystem, primarily the [lme4](https://CRAN.R-project.org/package=lme4) and [glmmTMB](https://CRAN.R-project.org/package=glmmTMB) packages. 

## Expected background

Participants should be familiar with the R language, linear statistical models and (ideally) generalized linear models. For exercises, please bring laptops with a current (>= 4.5) version of R and run the [package installation script](./install_pkgs.R).
